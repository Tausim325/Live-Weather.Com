Live Weather.Com

Live Weather.Com is a responsive weather application built with React.js and Material UI. It allows users to search for a city and view its current weather information using live data from the OpenWeather API.

*Features
*Search weather by city name
*Current temperature
*Feels-like temperature
*Humidity
*Minimum and maximum temperature
*Current weather condition
*Atmospheric pressure
*Sea level pressure
*Home button to return to the default weather
*Error message for invalid city searches
*Responsive design for desktop and mobile devices
*Dynamic weather background based on weather conditions

Technologies Used
React.js
Vite
Material UI (MUI)
JavaScript
HTML5
CSS3
OpenWeather API
React Router
